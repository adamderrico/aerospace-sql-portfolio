# Aircraft Sensor SQL Analysis

This project analyzes aircraft maintenance sensor data using SQL to explore patterns, identify risk factors, and generate engineering‑aligned insights. The goal was to build a clean, reproducible analysis pipeline that demonstrates data skills relevant to aerospace reliability, systems thinking, and technical problem‑solving.

## Dataset
The dataset includes aircraft sensor readings, maintenance events, and operational metadata. It was imported into PostgreSQL for structured analysis.

## Objectives
- Explore sensor behavior and maintenance patterns  
- Identify high‑risk aircraft or components  
- Apply engineering reasoning to data trends  
- Build a clear, well‑documented SQL workflow  

## Techniques Used
- Filtering and aggregation  
- JOINs across multiple tables  
- Window functions  
- Common Table Expressions (CTEs)  
- Risk scoring logic  
- Pattern detection  
- Final insights summarization
